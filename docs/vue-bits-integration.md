# Vue Bits integration

Registry sources: https://vue-bits.dev/r/{name}.json (retrieved 2026-10-15).

- RubberSegment: search segmented controls; preserve controlled value/change contract.
- Counter: profile metrics, compact formatting above 10,000; reduced motion shows static counts.
- Carousel: native scroll-snap image gallery in articles; preserve rich-text images and image preview.
- Stepper: publish stage indicator without hiding fields or changing submission validation.
- SwipeRow: own-content shortcuts with full-swipe commit disabled; explicit action remains available.
- SwipeToast: enhance existing Vant notifications with swipe dismissal; keep one notification system.
- SpringCheck: retain native checkboxes and add spring feedback to agreement/category selections.
- AnimatedList: first six comments enter once, appended pages remain immediate.
- Masonry: optional natural image ratios in discovery search, CSS columns preserve source order.
- CountUp: discovery total on initial data arrival; Counter used for changing profile metrics.
- AnimatedContent: submission result entry; FadeContent remains existing general fade wrapper.
- SquishSwitch: adapted as the discovery masonry view toggle; no new account preference or backend setting.
- PulseHeart/FadeContent: existing implementations retained.

Preserve keyboard controls, reduced motion, request error handling and KeepAlive restoration.
Tailwind utilities are scanned only from vendor components; no preflight/reset is imported.

Vendor source components: RubberSegment, Counter, SwipeRow. Other effects are native Vue/CSS/WAAPI adaptations of the registry interaction, preserving existing form and notification contracts.
